**Neon Coast Cover Studio** — an offline web app that turns any photo and a caption into multi-panel GTA-poster-style cover art, exported as a PNG to share. Four layouts (Vice Grid, Nine Panel, Full Bleed, Tilted Snaps), five sunset/neon colour grades, per-panel crop and positioning by drag and zoom, editable title and subtitle lettering, and one-step export in 1080 × 1080, 1080 × 1350 and 1920 × 1080. Photos never leave the machine; everything runs from static files with no network request. All art, lettering and fonts are original (Anton & Pacifico under the SIL Open Font License) — no game artwork, logos or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — add photos, pick a layout and grade, write the caption, and hit **Export PNG**.
